# DiPlay · 吉利星越 2019 款 8600 车机专用

本仓库已脱离原上游独立维护，仅服务**吉利星越 2019 款、8600 版本原厂车机（Android 4.3 / API18）**，当前重点为 USB CarPlay 适配。

截至2026-11-03：USB与HUD已进入实车验证；行驶对照确认原车高德零值覆盖造成HUD闪烁，用户卸载高德后反馈不再闪烁。**由DiPlay管理隔离的HUD独占测试包已交付，尚未装车**；USB稳定性和新包恢复行为继续分项验证，无线连接仍是后续规划。
