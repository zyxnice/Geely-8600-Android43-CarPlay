# DiPlay · 吉利星越 2019 款 8600 车机专用

本仓库已脱离原上游独立维护，仅服务**吉利星越 2019 款、8600 版本原厂车机（Android 4.3 / API18）**，当前重点为 USB CarPlay 适配。

2026-11-04：用户卸载原车高德并反馈 HUD 不闪后，已撤销独占模式；当前流畅度里程碑保留这一调整、媒体23／导航11及既有 USB 修复，不再禁用或恢复原车应用。

完整项目介绍、适用硬件与固件、当前验证状态、下载、反馈和许可统一维护在 **[项目首页 README.md](README.md)**。

当前 [USB 流畅度里程碑](docs/USB-SMOOTHNESS-MILESTONE-20261104.md)归档实车使用的 `7ef58d64cb92` APK：大部分滑动明显改善，仍偶发长停顿。
