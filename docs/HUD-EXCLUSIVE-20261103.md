## 使用与恢复

DiPlay 设置 →「吉利 HUD 导航试验」中新增「HUD 独占模式」，默认开启，HUD 总开关已有手动选择继续保留。

1. 收到有效 CarPlay 路线后，先确认原车高德已临时禁用、原本禁用或不存在，再输出 HUD。
2. 正常结束／断开先请求清屏，再恢复此前的原车高德启用状态。独占期间原车高德及依赖它的语音导航不可用。
3. 原本禁用或已卸载的高德保持原状，不自动启用或重新安装；安装身份发生变化时不套用旧恢复记录。
4. 「停止 HUD 并恢复原车导航」会同时关闭 HUD 总开关，避免下次回调重新接管。关闭独占开关也会停止 HUD；之后单独开启 HUD 会回到无隔离输出，可能再次竞争。
5. 导航 worker 以1秒节流续租，独立助手使用12秒租约。租约失效后尝试恢复；开机广播和应用启动另检查持久记录。手动恢复等待正常清屏，超过2秒撤销旧 owner 后尝试恢复。

原厂桥／PackageManager Binder 卡住、助手被系统杀死、开机广播未投递等情况不能保证自动恢复时限；恢复失败保留记录，待 DiPlay 再次运行或手动重试。已发出的 Binder 调用不能撤销。详见 [ADR-0010](adr/ADR-0010-hud-exclusive-navigation.md)。

回退旧 APK 前先停止 HUD 并核实高德恢复；旧 APK 不具备新恢复记录的处理逻辑。保留同签覆盖，不清除数据。
