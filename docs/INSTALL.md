# 吉利星越 2019 款 8600 车机安装与连接

当前发布为 [1.1](RELEASE-1.1-20261118.md)，APK 标识为 `1.1.0-H53-LOG` / versionCode 30；下载和校验文件见 [v1.1.0 Release](https://github.com/zyxnice/Geely-8600-Android43-CarPlay/releases/tag/v1.1.0)。

仅适用于本项目目标车型和车机。已记录环境为 GEELY NL5QJ / C3ALFUS、Android 4.3 / API18、固件 `06.03.08600.H53.00060`；其他固件需独立验证。

1.1 使用与原 1.0 相同的包名和签名，覆盖安装保留已有认证身份和应用数据；公开 APK 不含独立认证资产。
无线连接会读取原厂保存的热点信息并尝试开启热点，需在 DiPlay 选择已配对手机并核对实际热点状态。
自动连接未设置时默认启用，已保存的关闭选择仍会保留；自动热点未成功时可手动开启原车热点后重试。
本版音画同步、连接恢复和音乐连续性仍需实车验证，原始 [1.0](RELEASE-1.0-20261113.md) 保留作回退。

## 安装前

1. 核对车型年份、8600 版本及完整固件号，停车后操作。
2. 从[本仓库 Releases](https://github.com/zyxnice/Geely-8600-Android43-CarPlay/releases)选择明确标注星越 8600 的包；[独占测试包](HUD-EXCLUSIVE-20261103.md)已撤回，不再推荐安装。阅读说明、校验值与回退方法，不用其他车型或通用 APK 替代。
3. 保留当前可用 APK、应用设置和所需诊断记录。只有包名及签名一致的版本才能覆盖安装；不要为了绕过签名冲突直接卸载。
4. 本项目 8600 车测变体包名为 `com.shihab.diplay.repair1.geely8600`。源码普通 debug 包不等同于可独立连接手机的车测包，见[构建说明](BUILD.md)。

## USB 连接

1. 将适用 APK 安装到车机，关闭其他占用手机投屏或 USB 会话的应用。
2. 按应用实际提示授予所需权限，使用支持数据传输的线缆连接车机与已解锁 iPhone。
3. 选择应用中的 USB 连接入口，按实际出现的提示确认 USB 访问、信任或 CarPlay 授权。
4. 充电不代表数据链路建立。不能连接时记录提示、时间与固件号，按[8600 排查记录](GEELY-8600-HANDOFF.md)定位。记录中的驱动解绑、USB 模式切换等属于特定现场维护步骤，不是所有车辆的安装必做项。

## 验证与回退

- 分别检查画面、触控、音乐、导航声音、断线重连与冷启动恢复；单次连接成功不等于全部通过。
- 1.1 合入诊断功能；重点验证无线音画同步、热点自动开启、USB/无线重连、音乐连续性与暂停恢复。
- 1.1 的 versionCode 已升为 30，1.0 为 29；Android 安装器可能拒绝直接降级。需通过已授权的 ADB 使用 `adb install -r -d <1.0 APK>` 保留数据回退，不要为降级直接卸载；不支持该操作时停止并保留现场。
- 出现异常时停止测试，按该版本说明恢复先前可用包；覆盖安装仍需相同包名和签名。不要未经核对修改系统 USB 属性或刷写固件。

## HUD 导航

当前修订默认开启，保存手动关闭选择；升级身份以实际 APK SHA 为准，见[当前版本状态](GEELY-8600-STATUS.md)。

1. 收到有效导航元数据后直接通过原厂接收端输出 HUD，不操作原车高德启用状态。
2. HUD 默认开启并保存手动关闭选择，可在 DiPlay 设置中的 HUD 导航入口开启。
3. 用户卸载高德后反馈不闪，不需要为测试重新安装高德。分别观察路口信息、剩余距离、图标和导航声音。
4. 独占模式及恢复按钮已撤销；本次不远程安装、不发布新 APK。

历史独占包若曾在其他设备启用过，应先按其[历史恢复说明](HUD-EXCLUSIVE-20261103.md)核实恢复，再回退；旧版本不能处理独占恢复记录。

## 无线与其他功能

USB 专项验收继续推进，HUD 已进入受控实车试验与回归阶段。无线连接方案属于后续规划，具体方式与频段待核验；无线、5GHz、方向盘按键及免 root 全场景尚未验收。上游 Android 10+ Wi-Fi Direct、BYD 导航/电池等说明不属于本车型使用步骤。
