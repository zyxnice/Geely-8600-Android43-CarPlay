## 本次问题与处理

原车高德的后台服务及语音绑定可在用户没有打开导航时运行。trial1 以进程存在判断导航冲突，阻断了 HUD 输出；trial2 改为观察导航开始/结束和有效路线证据。未启用试验时的后台事件不再使后续试验一直失败；外源结束清除共享接收端后，仅重建仍获同意的试验输出，不自动恢复已因导航接管退出的试验。

USB 曾提示 `runtime_no_verified_response`：当时原厂命令进程运行，但 `COMMOND_Server` 查询未找到；用户手动重启后服务恢复，USB 准备通过并连上手机。这是本次观察到的恢复路径，尚未证实该服务问题的最初原因，也不能把所有 USB 失败归为同一原因。两秒空发现恢复不能替代准备阶段所需的原厂服务。
