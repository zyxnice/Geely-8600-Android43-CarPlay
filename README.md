# DiPlay · 吉利星越 2019 款 8600 车机专用

本项目仅面向**吉利星越 2019 款、8600 版本原厂车机**，维护 Android 4.3 / API18 环境下的 CarPlay 适配，当前重点为 USB 连接、音视频播放、触控响应、连接恢复与 HUD 导航。

仓库已脱离原上游独立维护。博瑞 H52、其他吉利车型、其他年份或车机版本、BYD 及通用 Android 车机均不在本项目支持范围内。即使系统版本相同，也不能据此认定兼容。

**独占模式的实际行为：**有效 CarPlay 导航期间临时禁用原车高德，确认隔离后输出 HUD，结束后恢复接管前状态。原本禁用或已卸载的高德保持原状，不自动安装。独占期间原车高德及依赖它的语音导航不可用；关闭独占或手动恢复会同时关闭 HUD 输出。

[下载独占测试包并查看校验值](docs/HUD-EXCLUSIVE-20261103.md) · [完整状态与历史记录](docs/GEELY-8600-STATUS.md) · [HUD 使用与恢复说明](docs/GEELY-8600-HUD.md)

11月1日至2日的 trial2、音频恢复和各轮排查记录保留在状态文档的历史部分，不代表新独占包已通过实车验收。无线连接及其他车型能力仍未验收。

## 下一步验证

1. **验证新 HUD 独占包**：高德未安装时确认 HUD／声音正常；高德安装状态下再验证行驶不闪、结束／断开恢复、手动恢复及异常／重启恢复。
2. **补齐 USB 与音画稳定性**：按既有清单验证重复启动、重连、音乐／导航声音、触控与长测，继续处理 VPN 重启授权问题。
3. **无线连接保留为后续规划**：当前没有已验证方案或上线时间承诺。

## 下载、安装与反馈

正式发布包查看[本仓库 Releases](https://github.com/zyxnice/Geely-8600-Android43-CarPlay/releases)。当前未装车的 [HUD 独占测试包](docs/HUD-EXCLUSIVE-20261103.md)通过项目 OSS 分发，不能视为正式稳定版。原上游 APK、H52 的 P21/P22 包以及其他车型的包不是星越 8600 的推荐下载。

公开源码树已移除旧 H52/P21 安装包，保留其历史说明与源码快照供追溯；不改写 Git 历史。

安装与使用步骤见[星越 8600 安装说明](docs/INSTALL.md)。本项目仍在适配与排查中，安装前请阅读对应版本的限制和回退说明。

问题请提交至[本仓库 Issues](https://github.com/zyxnice/Geely-8600-Android43-CarPlay/issues)，附上车型年份、完整固件号、APK 版本或文件名、iPhone/iOS 版本、连接方式和复现步骤。仅受理上述目标车型与车机范围的问题；诊断文件请先检查，勿公开凭据及配对记录。
