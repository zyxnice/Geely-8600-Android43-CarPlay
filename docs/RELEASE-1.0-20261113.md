## 后续重点：USB 与 Wi-Fi 流畅度

下一阶段同时优化 **USB 连接模式与 Wi-Fi 连接模式的画面、滑动及触控流畅度**。

1. 两种模式分别建立相同页面、手势与音乐状态下的实车基线，记录连续显示帧间隔及触控到显示延迟。
2. 依据证据区分接收、解密、解码、排队与实际显示阶段，再做最小改动；不能用连接成功代替流畅度验收。
3. 每轮验证流畅度改善，同时回归连接、音乐连续播放与暂停重播，保留 1.0 的可回退产物。

本次仅更新版本定位、发布与项目状态，没有实施新的流畅度调整。
