安装到目标车机

  1. 停车后核对车型、年份、8600 版本及完整固件号。
  2. 从项目候选记录或 Releases 选择匹配星越8600的包，阅读SHA、验收边界与回退说明；HUD独占测试包已撤回，不再推荐安装。
  3. 保留当前可用 APK 与设置。安装到车机，按实际提示授予权限；覆盖安装要求相同包名和签名。
  4. 使用支持数据传输的 USB 线连接已解锁 iPhone，选择 USB 连接入口并按实际提示完成授权。

充电不代表数据连接成功。驱动解绑和系统 USB 模式切换属于特定现场维护步骤，不是通用安装流程。
